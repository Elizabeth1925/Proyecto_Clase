## Instrucciones
Descarga el repositorio completo y abre el HTML con doble clic. Para las actividades 2, 3 y 4, conserva juntos `common.js`, `style.css` y los tres archivos HTML. Puedes arrastrar elementos, seleccionar opciones o escribir respuestas, según el ejercicio. Los resultados de práctica son locales y no se envían al docente automáticamente.

## Uso en clase
Los participantes se turnan entre los cuatro grupos. Se explica cada respuesta antes de avanzar. Las actividades 2–4 incluyen soluciones dentro del JavaScript porque son juegos de práctica; **no son las pruebas escritas oficiales**.
