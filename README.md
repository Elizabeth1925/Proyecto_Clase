## 🚀 Reto de Transformación
**Pregunta para la clase:** *"¿Cómo convertirían este diseño en una interfaz responsiva sin perder sus principios HCI?"*

**Solución demostrada:** 
Se utiliza un enfoque **"Mobile First"**, adaptando la disposición de los elementos y las áreas de clic (aplicando la *Ley de Fitts*) dependiendo de si el usuario está en un dispositivo táctil o usando un ratón en escritorio.

## 📋 Checklist de Requisitos APE 5
- [x] **Código fuente:** Estructura de archivos organizada (HTML separado de CSS).
- [x] **HTML5/CSS semántico:** Uso correcto de `<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`.
- [x] **Diseño Adaptativo (Mobile First):** CSS inicial enfocado en móviles, uso de Media Queries para Desktop.
- [x] **Componentes UI interactivos:** Botones y enlaces con estados (hover) y espaciado adecuado.
- [x] **Principios HCI:** Alto contraste, áreas de toque amplias en móviles y prevención de errores visuales.


## 🛠️ Tecnologías Usadas
* **HTML5:** Estructura y semántica
* **CSS3:** Flexbox, CSS Variables, Media Queries

## 🎭 Metodología de Demostración
Durante la clase se realizará una demostración contrastando la interfaz estática (`antes.html`) frente al modelo Mobile First (`index.html`) para visibilizar la pérdida de principios de usabilidad en dispositivos de pantallas pequeñas.
